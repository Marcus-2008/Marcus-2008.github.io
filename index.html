Uitgelicht project

F24 Motorsturing

Het sensor- en telemetriesysteem van een elektrische racekart, gebouwd voor het ICW-schoolproject met een team. Vijf sensormodules sturen data via LoRa naar een grondstation, dat alles vertaalt naar MQTT en live weergeeft op een dashboard gebouwd in Pygame — inclusief live positionering via de Yandex Maps API.

ADS1115 16-bit ADC · batterijspanning & stroommeting via I²C
MLX90614 Contactloze infrarood-temperatuursensor voor de motor
OT3686 Optische snelheidssensor · RPM via interrupt-telling
MicropyGPS NMEA-parsing voor live positie op het circuit
Python ESP32 MQTT LoRa Pygame
