Wie ben ik

Ik ben Marcus, gepassioneerd door netwerken en systeeminfrastructuur. Mijn focus ligt op stabiele en scherpe implementaties: firewalls opzetten met OPNsense, netwerken uittekenen in Cisco Packet Tracer, en fysieke deployments overeind houden.

Daarnaast bouw ik graag zelfstandig en in teamverband aan technische toepassingen. Mijn grootste project tot nu toe is F24 Motorsturing: het sensor- en telemetriesysteem van een elektrische racekart. Van I²C-sensoren tot een live dashboard — ik vind het net zo interessant om data te verzenden als om ze leesbaar te maken.

Uitgelicht project

F24 Motorsturing

Het sensor- en telemetriesysteem van een elektrische racekart, gebouwd in teamverband. Vijf sensormodules sturen data via LoRa naar een grondstation, dat alles vertaalt naar MQTT en live weergeeft op een dashboard gebouwd in Pygame — inclusief live positionering via de Yandex Maps API.

ADS1115 16-bit ADC · batterijspanning & stroommeting via I²C
MLX90614 Contactloze infrarood-temperatuursensor voor de motor
OT3686 Optische snelheidssensor · RPM via interrupt-telling
MicropyGPS NMEA-parsing voor live positie op het circuit
Python ESP32 MQTT LoRa Pygame

Hoe ik werk

Elk project volgt een gestructureerde aanpak, ongeacht de schaal.

Documentatie

Elk project krijgt een heldere README die uitlegt wát iets doet én waaróm — zoals bij F24, waar elke sensorkeuze grondig is onderbouwd.

Testen per onderdeel

Sensoren en modules worden modulair getest voor ze in het grotere geheel worden geïntegreerd — elk component in F24 beschikt over eigen testscripts.

Versiebeheer

Alle code en configuraties worden beheerd via Git, zodat de evolutie en historie van elk project transparant bewaard blijven.
